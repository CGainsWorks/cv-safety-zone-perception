# Export-time only.  Never installed into the runtime image.

# torch and yolox turn Megvii's YOLOX-Tiny COCO checkpoint into ONNX graphs
# (scripts/fetch_model.py) and onnxruntime's quantiser builds the INT8 graph
# (scripts/quantize_onnx.py).  YOLOX is Apache-2.0, code and weights alike;
# docs/licences.md has the detail.  Nothing under src/ imports torch or yolox,
# which keeps two gigabytes of wheel out of the runtime image.
#
# yolox itself is installed separately, because its setup.py imports torch to
# decide whether to compile an optional C++ COCO evaluator and so needs torch
# present and build isolation off:
#
#     pip install -r requirements-export.txt
#     pip install --no-deps --no-build-isolation -r requirements-yolox.txt
